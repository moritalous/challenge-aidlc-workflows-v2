## CLI インタラクション

| 画面 | トリガー | 結果 | エラー/エッジ |
|------|----------|------|---------------|
| 初回セットアップ(1-1) | Enter/続行 | 設定保存→意図入力(1-A1)へ | 認証失敗→1-2へ |
| 再起動(1-1b) | 起動 | セットアップ省略→1-A1へ直行 | — |
| セットアップ失敗(1-2) | `r`再試行 / `q`終了 | 再検証 / 終了 | 再試行も失敗→同画面に留まる |
| starter競合(1-A0) | 別の場所/中止 | 別ディレクトリ指定 / 中止 | 上書きはしない |
| 意図入力(1-A1) | 解析(Enter) | 解析中(1-A2)→要約(1-A3) | 空入力→再入力促し |
| 要約確認(1-A3) | 承認/編集(e) | 生成へ / 1-A1へループ | 必須情報欠落→1-A3e差し戻し |
| 生成結果(1-A5) | 品質ゲートへ(Enter) | ゲート(1-3)へ | ビルド/型不合格→ゲートで検出 |
| ゲート実行(1-3) | 自動 | 各柱を評価し状態更新 | FAIL→自動修正(1-3b,最大3); PENDING/ERRORは合格扱いにしない |
| 自動修正(1-3b) | 自動 | 試行カウンタ更新・全4柱再評価 | 部分合格=不合格として次試行; 3/3失敗→1-4 |
| エスカレーション(1-4) | (1)/(2)/(3) | 意図再実行 / 手動再投入 / 中断保存 | 中断後は再開可能 |
| デプロイ成功(1-5) | 自動 | 公開URL＋ヘルスチェック表示 | — |
| デプロイ失敗(1-5e) | `r`再試行/`q`中断 | ロールバック＋理由表示 | 自動不可時は手順提示; 非公開維持 |

### キー操作 / フォーカス
- 主要アクションは Enter、補助は単キー(r/q/1/2/3)。すべてキーボードのみで完了可能。
- ステータス更新はテキストでも逐次出力（スクリーンリーダー追従）。

## Web インタラクション

| 画面 | アクション | 結果 | エラー/エッジ |
|------|-----------|------|---------------|
| ログイン(2-1) | Sign in | 成功→一覧 | 失敗→alertでエラー文、入力保持 |
| 一覧(2-2) | + New Task | 作成画面へ | 0件→空状態CTA表示 |
| 一覧(2-2) | 行クリック/Enter | 詳細へ | — |
| 詳細(2-3) | Save | status通知「保存しました」→一覧 | 失敗→alert、入力値保持、再試行可 |
| 詳細(2-3) | Delete | 確認ダイアログ | キャンセル→変更なし; 確認→削除→一覧 |

### 状態遷移（詳細画面の保存）
```
[編集中] --Save--> [送信中] --成功--> [保存済(status通知)] --> 一覧
                          \--失敗--> [エラー(alert,入力保持)] --> [編集中]
```

## フィードバックの原則
- 成功: `role=status`(非割込, aria-live=polite)。
- 失敗/破壊的確認: `role=alert`(aria-live=assertive)。
- 破壊的操作(Delete)は必ず確認を挟む。デフォルトフォーカスは安全側(キャンセル)。
